# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/rootspawn` | Spawn area mapping and protection tools | `` | `/rootspawn map / import / build [chamber/well] / lava / stop / reload` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootspawn.build` | Map and refine spawn, chamber, well, and lava areas | `op` |
| `rootspawn.bypass` | Build and break inside the spawn no-build zone (group.admin also bypasses) | `op` |
| `rootspawn.chamber.bypass` | Ignore chamber 24h cooldown (testing) | `op` |
